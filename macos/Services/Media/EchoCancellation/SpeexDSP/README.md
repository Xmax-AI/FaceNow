# SpeexDSP

The echo canceller and SmallFT sources are from [SpeexDSP 1.2.1](https://github.com/xiph/speexdsp/tree/1b28a0f61bc31162979e1f26f3981fc3637095c8).
The upstream files are unmodified. The generated types header uses fixed-width C types.
FaceNow builds these files with floating-point processing and SmallFT. See SpeexDSP-LICENSE.txt.
